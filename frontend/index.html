Human Disease Prediction using Machine Learning

MedPredict turns a list of symptoms into a ranked set of likely conditions. A supervised classifier learns how symptoms co-occur across thousands of labelled cases, then estimates the probability of each disease for new input — with results explained in plain language alongside causes, red-flag warnings and self-care advice.

How it works

  1. 1

    Data collection

    A symptom–disease dataset is assembled and stored as CSV.

  2. 2

    Pre-processing

    Duplicates and missing values are removed and the data is balanced.

  3. 3

    Feature extraction

    Each case becomes a binary vector: one column per symptom.

  4. 4

    Model training

    A scikit-learn classifier is fit and evaluated on held-out data.

  5. 5

    Prediction API

    Flask endpoints return the top disease with class probabilities.
